# Findings: prolong-on-minecraft-qwen35

Decision-relevant only. Evidence pointer + confidence per row.

| # | date | finding | evidence | confidence | implication |
|---|---|---|---|---|---|
| 1 | 2026-08-15 | PRO-LONG is a *harness*, not a model: a runner appends every action/observation to `logs.txt`, and a coding-agent CLI (Codex or Claude Code) is invoked each turn with `Read/Write/Bash/Grep`, a persistent `/workspace/`, and one job — write `actions.json` = `{"actions": [...]}`. The runner executes that list, appends the results, and calls again. System prompt ~30 lines. | `prolong_agent/agent/prompts.py`; `environment/runner.py:270-330`; `agent/base.py:56-97` | high | The loop is environment-agnostic. Only three things are ARC-specific: the action vocabulary, `render_board`, and level/scorecard bookkeeping. That is the whole port surface. |
| 2 | 2026-08-15 | The environment seam is already abstract: `BaseEnv.reset/step -> (obs, reward, done)` with a single concrete implementation `ArcAgi3Env`. | `prolong_agent/environment/__init__.py:8-23` | high | A `MineExplorerEnv` slots in without touching the agent backends. |
| 3 | 2026-08-15 | Codex is invoked as `codex exec --json --skip-git-repo-check --ignore-user-config -o /workspace/last_message.txt -m <model> -c model_reasoning_effort=... -s danger-full-access <prompt>`, inside `docker run` with the workspace bind-mounted, on an `--internal` network reaching OpenAI only through a squid allowlist. Turn continuity via `codex exec resume <session_id>`. | `agent/codex_agent.py:381-406, 509-534`; `docker/codex-sandbox/Dockerfile` | high | Docker is used purely for isolation, not capability. On DeltaAI we drop it and run `codex` natively with `cwd=workspace`. `--ignore-user-config` means provider config must go through `-c`, not `config.toml`. |
| 4 | 2026-08-15 | The vendored aarch64 Codex binary (codex-cli 0.147.0) contains `model_providers`, `wire_api`, `base_url`, `env_key` and `view_image`. | `strings` on `@openai/codex-linux-arm64/vendor/aarch64-unknown-linux-musl/bin/codex` | medium | A custom OpenAI-compatible provider is expressible via `-c`, and the agent can pull a PNG from the workspace into the conversation — which is how frames reach a VLM in this architecture. Presence of the strings is not proof the path works with a non-OpenAI endpoint. |
| 5 | 2026-08-15 | `transformers serve` (5.12.1) implements `/v1/chat/completions` **with** `tools` passthrough and `tool_calls` parsing, plus `/v1/responses`, `/v1/models`, `/health`. | `transformers/cli/serving/chat_completion.py:157,172,263-284`; `serving/server.py:100-138` | high | Codex's tool-calling wire format is at least representable. Untested end to end against Codex. |
| 6 | 2026-08-15 | **Both benchmark scenes score exclusively on `position_near_with_facing`** — 0313 `(0,2,5) d≤5` and `(0,1,10) d≤4`; 0544 `(8,1,8) d≤8` and `(5,0,8)`; all spawn-relative, `facing_tolerance=60`. No rule inspects what is visible. | `benchmark/{0313,0544}/multi-agent/metadata.json` | high | Whatever positional information the log carries directly determines difficulty. This is the single most important design constraint on the port, and the reason arm A must be quarantined from reported scores. |
| 7 | 2026-08-15 | The current baseline **already** feeds numeric coordinates and pitch into the prompt (`_camera_state_hint`, `_movement_state_hint`), and only started doing so once the `info` passthrough was fixed. | `eval_benchmark.py:115-190, 395-396` | high | Arm B adds no information over the baseline — the comparison really is memory-architecture-only. Also means the 1/4 baseline was measured *with* these hints active. |
| 8 | 2026-08-15 | `MilestoneChecker.check(info)` is a pure function of `info`. | `benchmark_gen/milestone_checker.py:147` | high | Both arms can be scored by the identical, unmodified scorer — the comparison is clean by construction. |
| 9 | 2026-08-15 | `voxels` appears in the forwarded `info` but our server never registers `VoxelsCallback`, so it carries no blocks. When enabled it is a 15³ window of `{"type","x","y","z"}` dicts. | `mc_server.py:196-229`; `minestudio/simulator/callbacks/voxels.py:11-30`; `reward_gate.py:65-72` | high | A symbolic, greppable world state is one line away — the most PRO-LONG-native observation available — but enabling it changes the benchmark, so it belongs to arm A only. |
| 10 | 2026-08-15 | MineExplorer's action is already an LLM-emitted JSON object (`ActionState`: 24 binary keys + `camera[pitch,yaw]` + `hotbars[9]`, validated by pydantic). | `mc_agent/action_space.py:11-118` | high | Maps onto `actions.json` with almost no translation; add `repeat` so one plan spans many env ticks, since Minecraft actions are temporally extended in a way ARC's are not. |
| 11 | 2026-08-15 | `transformers serve` has no prefix caching, and PRO-LONG's prompt grows without bound by design. Each analyzer call is a full Codex turn = several internal LLM calls, each re-prefilling the whole log. | design constraint; baseline measured 13-24 s/step with a 20-frame buffer | medium | The dominant cost risk. Must be measured on a short pilot before any 300-step run; mitigations are `--log-window` and a floor on plan length. |
